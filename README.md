# Cricket Scoreboard System

A command-line based Cricket Scoreboard Management System developed using C programming.

## Features

* Team score tracking
* Player performance statistics
* Strike rate calculation
* Boundary count (4s and 6s)
* Match winner announcement
* Man of the Match display
* File handling support
* Interactive terminal-based interface

## Technologies Used

* C Programming
* Structures
* File Handling
* Conditional Statements
* Functions

## Project Overview

This project simulates a basic cricket scoreboard system where users can enter match details, player performances, and view the complete match summary.

The system calculates:

* Strike Rate
* Winning Team
* Match Summary
* Individual Player Statistics

All match records are also stored in a text file using file handling.

## How To Run

### Compile

gcc main.c -o scoreboard

### Execute

scoreboard.exe

## Sample Functionalities

* Enter Team Names
* Input Match Scores
